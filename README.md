# Portfolio · arico-dev

Portfolio personal brutalista de **arico-dev**, desarrollador web y estudiante.

Construido con **Vue 3** (`<script setup>`), **Vite** y **Tailwind CSS v4**, con iconos **Phosphor**. Diseño brutalista/minimalista con modo claro y oscuro, responsive y soporte de `prefers-reduced-motion`.

## Stack

- Vue 3 + Vite
- Tailwind CSS v4 (`@tailwindcss/vite`)
- @phosphor-icons/vue
- IntersectionObserver para reveal-on-scroll

## Contenido

- Hero con identidad y estado
- Stack de tecnologías
- Proyectos reales (datos en `src/data.js`)
- Sobre mí
- Contacto

Resuelto en `src/data.js`, sincronizado con el perfil público de GitHub de arico-dev.
